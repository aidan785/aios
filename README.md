# AIOS

A static snapshot of AIOS, a visual window into an AI operating system: every project, agent, connection and creative tool in one place. Built for the AIS Live VIP Room session "Design the Interface of Your AI OS" (October 17, 2026).

The live version runs on a local server that reads project folders, Claude Code logs, ClickUp and Google Calendar. This copy freezes that data as of the snapshot date, so search, file previews and agent runs are pre-recorded.
